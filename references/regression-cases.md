# 规则回归场景（2026-09-21）

用于改动规则后的逐项复核；全部为脱敏假设，不是实际审核结论。

| 输入情形 | 必须得到的结果 |
| --- | --- |
| 自驾，计算参数齐全，没有车辆借用证明 | 不要求车主/申请人关系证明，不因该项挂起 |
| 探亲结束后产生并开具加油发票，其他条件已齐全 | 日期项通过，不索要证明“只是延迟开票”的交易明细 |
| 有效总里程500公里、油耗8升/百公里、票据单价7.5元/升、申报油票280元 | 计算油费300元，油费认可280元，再适用探亲制度限额；不补足300元 |
| 同上，申报及油票320元 | 明确公式核减20元，其他项均通过时可PASS_WITH_DEDUCTION；不把整案默认核成1000元 |
| 缺百公里油耗或发票单价 | PENDING_EVIDENCE，暂不登记，不猜参数 |
| 备案为某市，目的地是该市辖县，路线截图公里数清楚 | 地点及里程可认可，不要求路线到市中心 |
| 假条签批完成，实际提前一天出发，报销材料明确因上夜班调整，无矛盾 | 行程日期项通过，不重复要求独立确认 |
| 提前一天但未写原因 | 不符合标准，待补具体原因；PENDING_EVIDENCE，暂不登记 |
| 行程提前两天 | 不套用一天规则自动通过，按实际制度交人工确认 |
| 培训电子合格证与人员课程对应，培训审批有效 | 证书项通过，不因无纸质证书挂起 |
| 仅有电子合格证，没有必要的培训/出差审批 | 证书项通过但整案仍PENDING_EVIDENCE，不登记 |
| 培训没有产生住宿费 | 住宿不适用，不索要住宿票据 |
| 培训加油及过路费齐全，发生/开票都在培训期间并对应路线 | 交通日期项通过，金额仍按标准核对 |
| 扣减明确且所有其他证据完整 | 简明结论给出PASS_WITH_DEDUCTION、最终金额、可登记及一句扣减原因 |
| 有任何真实缺件或未决冲突 | 简明结论明确暂不登记及关键待办，不输出“可以通过” |

计算复核：`500 / 100 × 8 × 7.5 = 300.00`。多个票价的分摊不明、里程重复、票据重复等不得借简明输出隐藏；详细底稿仍须保留。
